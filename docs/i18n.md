# Internationalization

i18n is optional but ready.

## Routing Policy

- Default locale: `en`.
- Default locale has no prefix: `/about`.
- Secondary locales use a prefix: `/el/about`.

Configure locales in `src/template.config.ts`.

## Helpers

- `localizedField()` resolves localized CMS field values.
- `localePath()` returns the correct URL path for a locale.
- `canonicalForLocale()` returns an absolute canonical URL.
- `alternateLocales()` creates `hreflang` metadata for layout and sitemap output.

## Implementation Notes

The template does not force every project to be multilingual. Keep `i18nEnabled: false` for single-language projects. When enabling i18n, add localized routes or dynamic route generation for the pages that need translated content.
