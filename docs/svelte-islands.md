# Svelte Islands

Astro remains the shell. Svelte is available only for interactive islands.

## Use Svelte For

- accessibility menu state if the local Astro version becomes too complex
- mobile navigation
- filters/search
- media player controls
- gallery controls
- enhanced newsletter feedback

## Avoid Svelte For

- static page layout
- static content rendering
- simple links, headings, and copy

## Example

`src/components/islands/IslandStatus.svelte` is a tiny hydration example used on the homepage. Replace or remove it in client projects.
